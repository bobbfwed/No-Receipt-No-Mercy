## What was done

### The Remove tool no longer crashes on a touch tap
- **Your report:** during a sales event, tapping a Sprinkler to remove it put an error banner across the top; after a few tries it went.
- **Cause:** with the Remove tool held, a tap made the touch code look the tool up in the list of buildings, to see whether it was bigger than one tile. Remove is not a building, so that threw an error and the remove was never sent. The red banner is the page's catch-all error message.
- **Why it worked after a few tries:** a finger that slides 10 pixels counts as a drag, and a drag with the Remove tool works. So does the Remove button on a building's own sheet.
- **Scope:** any building, any time, touch taps only. It has been there since 0.2.01. The installed app made no difference.
- **Fix:** one line in `src/ui/input.js`. The touch test page has four new checks (38 in all) that tap a one-tile and a four-tile building with the Remove tool; they fail without the fix and pass with it.

### The handbook's tables run to sales event 30
- Every shopper's table shows events 1, 5, 10, 15, 20, 25 and 30, whether opened from the menu or inside a game of any length. An endless game shows further.
- The range comes from the longest length on offer in the settings, so it follows if that list changes.
- To fit seven columns on a phone, "How many" is split into two short rows.

### Normal is the baseline
- Normal is exactly 0% on patience and income, described as "The standard game. Every number in the handbook is for this one."
- The base numbers are now what a Normal game really uses (a Bargain Hunter's patience reads 36, not 40). A scripted Normal game plays identically to before, line for line.
- Easy: patience -25%, income +25%. Hard: +30%, -15%. Brutal: +65%, -30%.
- Help and tutorial text quoted $7 for a Gadget and $16 for a Gift Set; a Normal game has always paid $8 and $18, and they now say so.

### The Soccer Mom chases at twice the ordinary mom's speed
- It was three times. Her help, handbook and README text say "twice".
